# Рабочая папка My Day

Эта папка объединяет локальные копии одного проекта. Репозиторий и правила разработки находятся в `main`. Перед работой прочитай `main/AGENTS.md` и `main/docs/STATUS.md`.

- `main` содержит опубликованный код. `test` предназначена для проверок с тестовыми данными.
- Для отдельной задачи исполнителя используй `main/tools/workspace/New-MyDayWorkspace.ps1`. Копии создаются в `projects/<источник>/<задача>`. Работай в каталоге своей задачи, в том числе если чат открылся в другом месте.
- Инструкция по карантину, восстановлению, распределению задач и выпуску версий находится в `main/docs/WORKSPACE.md`.
