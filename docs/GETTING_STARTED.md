# Подключение Google Drive

Сайт использует существующий Default Gemini Project. Уже настроены Drive API, Google Picker API, OAuth web client, тестовый аккаунт и ограниченный ключ My Day Picker. Разрешение сайта — `drive.file`, разрешённый JavaScript origin — `https://ltstripes.github.io`. В 0.1.1 владелец и помощник подтвердили обмен на одном тестовом Markdown. [Открыть сайт](https://ltstripes.github.io/My-day-/)

## Короткий ежедневный маршрут

1. Открой My Day и при необходимости нажми «Подключиться снова». На личном устройстве с сохранённой настройкой повторный Picker не нужен.
2. Посмотри «Сегодня» и выбранный план. Источники и время их чтения указаны рядом.
3. Нажми «Записать мысль», введи текст и «Добавить в Drive». Дождись подтверждения. При ошибке сохрани черновик и используй предложенный повтор.
4. Для разбора открой очередь помощника, выбери мысль, скопируй команду в свой чат с Drive. Когда ответ записан, вернись в ту же вкладку.
5. Для чтения результата открой ответ в контексте заметки. Если он ещё не появился, обнови нужный файл.
6. На общем компьютере закончи сеанс кнопкой «Отключиться» и закрой приватное окно.

## Дела в 0.12.0

1. В блоке «Сегодня» нажми **«Выбрать To Do now.md»**. Для проверки записи выбери файл из папки приёмки **«My Day — приёмка 0.10.0»**. Его первая строка — «Посмотреть маршрут прогулки».
2. Рядом с обычным пунктом нет кнопки. У задачи **«Проверить фонарик»** нажми **«Выполнено»**. Дождись подтверждения чтением из Drive. Задача исчезнет из открытых, количество выполненных увеличится.
3. Нажми **«Обновить обзор»**. Затем открой **«Открыть в Drive»** под списком. У фонарика должен быть `[x]`, два соседних пункта должны сохраниться. Если этот файл синхронизируется с Obsidian, проверь тот же флажок там.
4. Чтобы вернуть привычный обзор, снова нажми **«Выбрать To Do now.md»** и выбери свой файл. Обычный список читается без заголовка. При наличии раздела сегодняшнего дня карточка показывает пункты этого раздела.

Если Drive сообщил об изменении файла, проверь перечитанный список и заново выбери дело. При обрыве сети нажми «Обновить обзор» после восстановления связи. Кнопка доступна для открытых флажков в редактируемом файле.

При повторной отправке мысли в Inbox сайт сверяет текст и метку операции. Смена окончаний строк в редакторе допустима. При неоднозначной метке или изменении самой мысли черновик остаётся для сверки.

## Планы на каждый день в 0.11.0

1. Открой тестовый Inbox и начни черновик. В **«Планах»** нажми **«Выбрать план»** для первого файла и **«Добавить план»** для следующего. Если план уже был выбран в 0.10.0, повторно выбирать его не нужно. Для приёмки подойдут `План прогулки — тест.md` и `План покупок — тест.md`.
2. Переключись на план прогулки. В общем **«Поиске»** введи `рюкзак` и нажми **«Найти»**. Открой совпадение из плана покупок. В строке «Проверить, помещается ли термос в рюкзак» будет подсвечено слово **«рюкзак»**. Поиск читает все выбранные планы и заметки, включая планы, которые сейчас закрыты.
3. В списке планов выбери **«План покупок — тест.md»** и нажми **«Закрепить на сегодня»**. В карточке появится **«Сравнить два термоса»**. Переключись обратно на прогулку. На «Сегодня» останутся покупки; по ссылке карточки можно открыть полный файл в Drive.
4. Вернись к черновику и сверь текст и название Inbox. На личном устройстве с включённым запоминанием список и закрепление восстанавливаются после подключения. В общем режиме они действуют в текущей вкладке.

## Общая приёмка 0.10.0

Для проверок записи используй отдельный `My-Day-test.md`. В папке приёмки есть тестовая мысль без ответа и пример плана. Ссылка на личную папку передана владельцу в чате.

1. **Мысль и ответ.** В привычной тестовой заметке открой **«К помощнику»**, выбери мысль с ответом и нажми **«Открыть ответ в заметке»**. Ожидается подсветка именно этого ответа. **«К очереди мыслей»** возвращает к прежнему выбору.
2. **Личный день.** Выбери свой Inbox и два источника экрана «Сегодня». Сверь фокус, дело и подпись **«Запись в Мысли.md»**. Для этой проверки достаточно чтения. [Какие кнопки нажать](#подключение-личных-заметок)
3. **Отказ помощнику.** Для этой проверки сайт должен использовать аккаунт с правом редактирования отдельного тестового файла, а чат — подключение, которому этот файл доступен только для чтения. В тестовой заметке выбери мысль без ответа, отправь её команду в такой чат и вернись на сайт. Ожидается явное сообщение в чате о невозможности записать результат. После обновления мысль остаётся в группе «Без ответа», контрольная строка сохраняется. Если подключение помощника принадлежит владельцу файла, этот сценарий пока пропусти.
4. **План.** Открой **«Планы» → «Выбрать план»** и укажи `План прогулки — тест.md`. В карточке появится **«Сверить время электрички»**. Открой план в Drive, отметь этот тестовый пункт выполненным и нажми на сайте **«Обновить план»**. Следующим будет **«Найти дорожку до озера»**. Отправка мысли по-прежнему ведёт в Inbox. На личном устройстве выбор плана сохраняется с согласия, в общем режиме действует в текущей вкладке.
5. **Телефон.** С выключенным домашним ноутбуком открой сайт на телефоне, подключи тестовую заметку, добавь уникальную короткую мысль. После подтверждения перезагрузи страницу и при необходимости подключись снова. Мысль должна встретиться в заметке один раз. Открой команду для этой мысли в своём чате и вернись после записи ответа.
6. **Рабочий компьютер.** Когда это будет доступно, открой сайт из разрешённого рабочего браузера. Оставь флажок **«Запомнить на личном устройстве»** снятым. Прочитай тестовый файл, нажми **«Отключиться»**, закрой вкладку и открой сайт снова. Текст и прежний выбор должны исчезнуть. Если сеть не разрешает вход Google, достаточно записать, на каком шаге он остановился.

## Чтение мысли и ответа в 0.9.0

1. Открой `My-Day-test.md`. В разделе **«Помощник»** выбери мысль и нажми **«Открыть мысль в заметке»**. Подсветка укажет начало выбранной мысли. Выше и ниже можно читать исходный текст.
2. Нажми **«К очереди мыслей»**, выбери запись с подтверждённым ответом и нажми **«Открыть ответ в заметке»**. Подсветка переместится к началу ответа. Возврат сохраняет фильтр и выбранную запись.

## Подключение личных заметок

Эти действия можно выполнить на своём устройстве после проверки на тестовом файле. Если файл уже выбран, достаточно сверить его название и содержимое. Перед сменой заметки заверши начатый черновик или оставь его до следующего раза.

1. В **«Мои заметки» → «Выбрать файл»** укажи существующий `Мысли.md` из своего Inbox. Проверь подпись **«Запись в Мысли.md»** и знакомый фрагмент в окне чтения. Выбор файла сам по себе ничего в него не добавляет.
2. На экране **«Сегодня»** нажми **«Выбрать Now.md»** у карточки **«Текущий фокус»**, затем **«Выбрать To Do now.md»** у карточки дел. Укажи свои одноимённые файлы. По ссылкам **«Открыть в Drive»** можно проверить источник каждой карточки.
3. Нажми **«Обновить обзор»**, сверь фокус и дела с Drive. Нажми **«Записать мысль»** и проверь, что курсор перешёл в поле Inbox. Для этой сверки отправлять запись не нужно.

## Очередь мыслей в 0.8.0

1. Открой `My-Day-test.md`. На экране **«Сегодня»** нажми **«К помощнику»**. Счётчики относятся к открытой заметке. В очередь попадают мысли, сохранённые через My Day.
2. Выбери фильтр **«Без ответа»**, открой команду нужной мысли и отправь её в свой чат с доступом к Drive. Если список пуст, можно создать тестовую мысль через **«Добавить в Drive»**.
3. После подтверждения записи вернись в ту же вкладку. Проверь первую строку ответа и обновлённый счётчик. Нажми **«Следующая без ответа»**, если в очереди есть ещё мысли. Фильтр **«С ответом»** поможет перечитать результат позже.

## Возврат из чата в 0.7.1

1. Открой `My-Day-test.md` и выбери мысль в разделе **«Помощник»**. Открой команду и скопируй её.
2. Переключись в чат с помощником, отправь команду и дождись подтверждения записи.
3. Вернись в открытую вкладку My Day. Сайт проверит выбранную мысль и покажет первую строку ответа. Если вернулся до того, как помощник закончил, можно нажать **«Обновить»** после его подтверждения. При истёкшем доступе сайт предложит повторный вход.

## Выбор мысли в 0.7.0

1. Подключи Drive и открой существующий `My-Day-test.md`. Перейди к разделу **«Помощник»**. Если в файле несколько записей из My Day, в списке **«Сохранённая запись»** первой идёт самая новая.
2. Выбери более раннюю мысль. Рядом появится состояние её разбора. Для записи с привязанным ответом видна его первая строка. Полный текст остаётся в заметке. Если метки ответа пусты или неоднозначны, сайт сообщает об этом.
3. Чтобы передать мысль в чат, открой и скопируй команду. Когда помощник подтвердит запись, вернись на сайт. У выбранной мысли появится ответ. Для проверки выбора достаточно первых двух шагов.

## Обновление вкладки в 0.6.1

1. На личном устройстве включи **«Запомнить на личном устройстве»**, подключи Drive и открой тестовую заметку. В окне чтения должны быть видны мысли и ответы помощника. Строки со служебными идентификаторами скрыты.
2. Введи пару слов в черновик и нажми **F5** в той же вкладке. При действующем доступе и поддержке браузера заметка загрузится заново, появится свежее время чтения, а черновик останется в поле ввода.
3. В новой вкладке, в общем режиме, при истёкшем доступе или недоступной передаче появится кнопка подключения. На личном устройстве выбранный файл откроется после входа.

## Разбор мысли в 0.6.0

1. Подключи Drive и открой `My-Day-test.md`. Для пробы добавь мысль «Хочу выбрать книгу на выходные» и дождись подтверждения записи.
2. В разделе «Помощник» нажми **«Разобрать последнюю запись»**, затем **«Скопировать команду»**. Если браузер попросит, скопируй выделенный текст вручную. Вставь в свой чат с подключённым Google Drive и отправь. Команда указывает файл и метку сохранённой мысли.
3. После подтверждения помощника вернись на сайт. Для ручной проверки нажми **«Обновить»**. В том же файле должны быть видны исходная мысль и результат разбора. Повтор той же команды должен вернуть уже сохранённый результат. При недоступности Drive помощник должен сообщить об этом в чате.

Одну мысль разбирай в одном чате за раз. Для уже сохранённого результата помощник проверяет ту же метку. Если в тексте есть вручную вставленные служебные метки и границы записи неясны, помощник попросит уточнение.

## Поиск в 0.5.0

1. Открой [My Day](https://ltstripes.github.io/My-day-/), нажми **«Подключиться снова»**, затем **«Поиск»** вверху страницы. Для пробы подходит уже выбранный My-Day-test.md.
2. Введи слово или фразу из заметки и нажми **«Найти»** или **Enter**. Поиск охватывает имена и текст явно выбранных файлов, учитывает мягкие переносы строк и находит «перелёт» по запросу «перелет». У одноимённых файлов показаны их ID. Кнопка **«Ещё совпадения»** раскрывает следующую часть выдачи.
3. Нажми найденную строку. Откроется исходный текст с подсветкой, временем чтения и ссылкой на файл в Drive. **«К результатам»** возвращает к поиску. Если есть начатая мысль, **«К черновику»** возвращает к ней.

Для проверки внешней правки повторно нажми «Найти». При недоступности файла в выдаче появится причина и число прочитанных файлов. Ввод запроса и просмотр уже найденного фрагмента выполняются в браузере. «Очистить поиск» убирает запрос, результаты и просмотр заметки. Выход из Drive также очищает их.

## Сегодня в 0.4.0

1. Открой [My Day](https://ltstripes.github.io/My-day-/) и нажми **«Подключиться снова»**. Если в 0.3.0 ты уже выбрал по одному Now.md и To Do now.md, их содержимое появится сразу после входа.
2. Если источник ещё нужен, нажми **«Выбрать Now.md»** или **«Выбрать To Do now.md»** под соответствующей карточкой и укажи свой файл в Picker. Можно начать с одной заметки. Если есть одноимённые копии, укажи нужную. Карточки читают выбранные файлы по их Drive ID.
3. **«Обновить обзор»** перечитывает источники и показывает внешние правки. У каждой карточки своё время чтения. При потере сети видно, какие данные устарели. Если Drive отказал в доступе к файлу, его текст исчезает. Повторное подключение начинает новую сессию.
4. **«Записать мысль»** открывает ввод в выбранный Inbox. При первом обращении выбери существующий Мысли.md. Для уже начатой записи кнопка **«К черновику»** возвращает к её исходному файлу. Чтобы отправить текст, нажми **«Добавить в Drive»**.

Карточка дел показывает незавершённые Markdown-пункты вида `- [ ]` под заголовком **Сегодня** или с текущей датой в формате **ГГГГ-ММ-ДД**, включая вложенные темы. Например, под `## 2026-11-25` можно поместить `- [ ] Купить билет`. Если раздела дня нет, карточка называется **«Открытые дела»** и показывает незавершённые пункты файла. Дата и полночь определяются по часовому поясу, указанному рядом с датой. Карточки доступны для чтения. Сами дела редактируются в исходной заметке.

## Заметки в 0.3.0

1. Открой [My Day](https://ltstripes.github.io/My-day-/) и нажми **«Подключиться снова»**. На уже настроенном личном устройстве откроется последний файл. Если Google попросит, подтверди вход. При первом подключении отметь личный режим только на своём устройстве и введи ограниченный ключ Picker.
2. Для пробы продолжай работать с **My-Day-test.md**. Для обычной работы нажми **«Выбрать файл»** и укажи существующий **Мысли.md** из своего Inbox. Поле ввода покажет «Запись в Мысли.md». Введи мысль и нажми **«Добавить в Drive»**. Подтверждение появится после повторного чтения.
3. Через ту же кнопку выбери **Now.md** и **To Do now.md** по очереди. Каждая заметка откроется с пометкой «только чтение». Для перехода между уже выбранными заметками используй список над кнопками. Если есть черновик, сначала отправь его или явно очисти.

На личном устройстве My Day перенесёт совместимый черновик 0.1.1 вместе с ID исходного файла и меткой записи. Если есть более новый черновик или выбран другой файл, прежняя копия остаётся доступна отдельно. На общем компьютере перенос запускается кнопкой «Восстановить старый черновик».

## Приёмка 0.2.0

1. **Первый вход на личном ноутбуке.** Открой сайт. Отметь «Запомнить на личном устройстве», введи свой ограниченный ключ Picker и оставь уже заполненный номер проекта. Нажми «Подключить Google Drive», подтверди Google при запросе и через «Выбрать файл» укажи существующий `My-Day-test.md`. Появятся текст и время чтения.
2. **Возврат на сайт.** Введи «Проверка возврата 0.2.0» и закрой вкладку до отправки. Открой сайт заново. Флажок и черновик должны восстановиться. Нажми «Подключиться снова». Тот же файл должен загрузиться автоматически. Чтобы проверить свежесть, пока вкладка закрыта, можно попросить подключённого помощника дописать одну тестовую строку в этот же файл с сохранением ID. При входе она должна быть видна сразу.
3. **Сбой и повтор.** Оставь вкладку открытой, временно отключи сеть на ноутбуке и нажми «Добавить в Drive». После сообщения об ошибке включи сеть. Если сайт предлагает повторный вход, нажми «Подключиться снова». Нажми «Проверить и повторить». В Drive должна быть ровно одна строка «Проверка возврата 0.2.0», исходный текст должен сохраниться, поле ввода очиститься. Для повторного прогона возьми другой тестовый текст.
4. **Общий компьютер.** Открой сайт в новом приватном окне. Флажок должен быть снят, ключ и черновик пусты. Если проверяешь запись, оставь флажок снятым и используй тот же тестовый Markdown. Общий режим хранит текст только до закрытия вкладки. На чужом компьютере закончи работу кнопкой «Отключиться» и закрой приватное окно.
5. **Удаление настроек.** В обычном окне на личном ноутбуке нажми «Забыть это устройство». При наличии черновика сайт попросит подтверждение. После обновления флажок снят, ключ пуст, выбранных файлов и черновика нет. Запись можно проверить в самом Drive. Если хочешь оставить подключение настроенным, выполни проверку удаления в отдельном профиле браузера.

Если в 0.1.1 оставалась незавершённая отправка, сайт предложит **«Восстановить старый черновик»**. Сначала выбери нужный режим устройства. Сохранятся исходный файл и метка отправки. Для первого выбора уже загруженный Markdown подходит повторно. Чистый [шаблон My-Day-test.md](../web/My-Day-test.md) пригодится, если тестового файла ещё нет.

## Срок доступа и восстановление

- При истечении доступа или ответе Drive HTTP 401 нажми «Подключиться снова» и подтверди доступ в Google при запросе. Сайт перечитает выбранный файл. Чтобы попробовать этот путь сразу, на личном устройстве нажми «Отключиться», затем «Подключиться снова».
- Если Google отозвал доступ к файлу или аккаунт его не видит, проверь аккаунт и право чтения, а для Inbox или тестовой записи — право редактирования. Через «Выбрать файл» укажи тот же Markdown. Черновик привязан к его Drive ID. В личном режиме «Отключиться» позволяет выбрать другой аккаунт при следующем входе.
- Если результат отправки неизвестен, «Проверить и повторить» ищет метку и точный текст на Drive. При совпадении повтор обходится без записи. При конфликте текста сайт сохраняет черновик для ручной сверки. Проверка версии перед записью обнаруживает изменения между чтениями. Одновременные действия других клиентов между финальной проверкой и обновлением по-прежнему возможны.
- В общем режиме до подтверждения записи держи вкладку открытой. В личном режиме браузер сохраняет настройки и черновик в этом профиле. Если браузер блокирует сохранение, сайт показывает предупреждение. Ошибка чтения сохраняет время последнего успешного чтения либо явно показывает, что файл ещё предстоит прочитать.

## Настройка Google, если нужно сверить параметры

В Google Cloud Console выбери существующий проект и открой **APIs & Services → Enabled APIs & services**. Для проекта должны быть включены Google Drive API и Google Picker API. В Google Auth Platform у веб-клиента указан точный origin сайта без пути, а личный аккаунт добавлен в тестовые пользователи. Ошибку `SERVICE_DISABLED` в 0.1.1 устранило включение Google Drive API именно в проекте OAuth-клиента.

Ключ Picker ограничивается по HTTP referrer сайта и API в Cloud Console. В поле My Day вводится только этот браузерный ключ. OAuth client secret, access/refresh token и ключи моделей для настройки не нужны. Сайт получает краткоживущий токен от Google при явном нажатии кнопки. Помощник использует собственное подключение Drive.
