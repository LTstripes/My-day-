# Первый шаг: подключение Google Drive

Обновлено 25.11.2026. Это инструкция подготовки, не отчёт о настроенном доступе. Первая публикация GitHub Pages завершилась успешно. Код тестовой страницы добавлен, живая авторизация и чтение/запись ещё требуют приёмки.

## Что делаем первым

Обычный сайт для ноутбука читает и дополняет выбранные Markdown-файлы непосредственно на Google Drive. Помощник отдельно работает с этими же файлами. Android и виджеты — позже.

## Текущая настройка (25.11.2026)

Из-за лимита новых Cloud projects владелец использует Default Gemini Project. По его сообщениям, Drive API, Picker API, Branding, test user, drive.file, Web OAuth client и ограниченный ключ Picker настроены. Адрес сайта: https://ltstripes.github.io/My-day-/ ; JavaScript origin: https://ltstripes.github.io . Сам ключ не коммитится: вводится на тестовой странице; номер проекта сверяется в Cloud Console. Первый Pages workflow завершился success. Код новой страницы нужно проверить после следующей публикации.

Для теста скачай шаблон My-Day-test.md с сайта, загрузи обычным файлом на свой Drive, введи ограниченный ключ Picker на сайте, подключи Google и выбери этот файл. Используй только синтетический текст. Доступ помощника проверяется отдельно.

## Шаг 1 для владельца (история настройки)

1. Открыть [Google Cloud Console](https://console.cloud.google.com/) под личным Google-аккаунтом, в котором находится Obsidian.
2. Через выбор проекта создать отдельный проект с названием **My Day**. Если такой проект уже создан, использовать его; одинаковые проекты не нужны.
3. Убедиться, что выбран именно My Day, затем открыть **APIs & Services → Library** («API и сервисы → Библиотека»).
4. Найти и включить **Google Drive API**.
5. Найти и включить **Google Picker API**.

Результат шага: проект выбран, оба API имеют статус Enabled/«Включено». В ответ достаточно написать «готово» или показать экран того места, где возникло затруднение. На этом шаге не нужны OAuth client secret, токены или ключ модели.

По текущей документации Google стандартный уровень Workspace API доступен без Cloud Billing account и банковской карты; новый проект начинает с этого уровня. Повышенный платный уровень для этой проверки не нужен. Если интерфейс неожиданно требует дополнительные условия, сначала разобрать именно показанный экран.

## Что подготовить следующим

Когда известен точный HTTPS-адрес сайта, разработчик даёт владельцу следующий короткий блок действий:

- Настроить Google Auth platform: название My Day, контактный email, внешний тип приложения для личного аккаунта и собственный аккаунт как test user.
- Добавить минимальное разрешение `https://www.googleapis.com/auth/drive.file`.
- Создать OAuth client типа Web application с точным Authorized JavaScript origin сайта. В origin входят схема и хост, без пути; адрес не угадывать до выбора размещения.
- Настроить ограниченный браузерный API key для Google Picker по актуальной инструкции Google; учесть ограничения по referrers и API.
- Передать в конфигурацию OAuth client ID, номер Cloud-проекта и ключ Picker. OAuth client secret и Google access/refresh tokens в чат и исходники не передавать.

Сейчас эти действия выполнять вслепую не требуется: сначала нужен точный адрес сайта. Браузерный token model не использует client secret для серверного обмена.

## Первый работающий результат

1. На сайте нажать «Подключить Google Drive» и выбрать Google-аккаунт.
2. Через Google Picker выбрать отдельный тестовый `.md` с синтетическим текстом. Выбор файла выдаёт приложению ограниченный доступ; одна ссылка на файл этого не делает.
3. Увидеть содержимое, добавить одну запись и перечитать сохранённый файл.
4. Попросить подключённого помощника прочитать эту запись и сделать согласованную тестовую правку.
5. Нажать «Обновить» на сайте и увидеть правку.

После этого подключать по выбору владельца привычные `Мысли.md`, `Now` и `To Do now`, сохраняя существующую организацию Obsidian. Не перемещать vault и не делать его публичным ради подключения.

## Ограничения первого варианта

- Google access token краткоживущий. После истечения доступа пользователь снова нажимает кнопку подключения; вечная фоновая сессия не обещается.
- Закрытая страница сама не выполняет разбор записей. Модель запускается явным запросом либо отдельным уже действующим процессом.
- Права Google Drive-коннектора в чате не становятся автоматически правами сайта. У сайта собственное разрешение Google.
- `drive.file` относится к выбранным/созданным приложением файлам. Выбор папки не считается автоматическим доступом ко всему существующему vault.
- Google Calendar подключается отдельно, если понадобятся его события.
- Прямой доступ Android к тем же файлам проверяется на Android-этапе; он не блокирует первый сайт.
