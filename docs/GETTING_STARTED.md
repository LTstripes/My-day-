# Подключение Google Drive

Сайт использует существующий Default Gemini Project. Уже настроены Drive API, Google Picker API, OAuth web client, тестовый аккаунт и ограниченный ключ My Day Picker. Разрешение сайта — `drive.file`, разрешённый JavaScript origin — `https://ltstripes.github.io`. В 0.1.1 владелец и помощник подтвердили обмен на одном тестовом Markdown. [Открыть сайт](https://ltstripes.github.io/My-day-/)

## Приёмка 0.2.0

1. **Первый вход на личном ноутбуке.** Открой сайт с пометкой **0.2.0**. Отметь «Запомнить на личном устройстве», введи свой ограниченный ключ Picker и оставь уже заполненный номер проекта. Нажми «Подключить Google Drive», подтверди Google при запросе и через «Выбрать файл» укажи существующий `My-Day-test.md`. Появятся текст и время чтения.
2. **Возврат на сайт.** Введи «Проверка возврата 0.2.0» и закрой вкладку до отправки. Открой сайт заново. Флажок и черновик должны восстановиться. Нажми «Подключиться снова». Тот же файл должен загрузиться автоматически. Чтобы проверить свежесть, пока вкладка закрыта, можно попросить подключённого помощника дописать одну тестовую строку в этот же файл с сохранением ID. При входе она должна быть видна сразу.
3. **Сбой и повтор.** Оставь вкладку открытой, временно отключи сеть на ноутбуке и нажми «Добавить в Drive». После сообщения об ошибке включи сеть. Если сайт предлагает повторный вход, нажми «Подключиться снова». Нажми «Проверить и повторить». В Drive должна быть ровно одна строка «Проверка возврата 0.2.0», исходный текст должен сохраниться, поле ввода очиститься. Для повторного прогона возьми другой тестовый текст.
4. **Общий компьютер.** Открой сайт в новом приватном окне. Флажок должен быть снят, ключ и черновик пусты. Если проверяешь запись, оставь флажок снятым и используй тот же тестовый Markdown. Общий режим хранит текст только до закрытия вкладки. На чужом компьютере закончи работу кнопкой «Отключиться» и закрой приватное окно.
5. **Удаление настроек.** В обычном окне на личном ноутбуке нажми «Забыть это устройство». При наличии черновика сайт попросит подтверждение. После обновления флажок снят, ключ пуст, выбранных файлов и черновика нет. Запись можно проверить в самом Drive. Если хочешь оставить подключение настроенным, выполни проверку удаления в отдельном профиле браузера.

Если в 0.1.1 оставалась незавершённая отправка, сайт предложит **«Восстановить старый черновик»**. Сначала выбери нужный режим устройства. Сохранятся исходный файл и метка отправки. Для первого выбора уже загруженный Markdown подходит повторно. Чистый [шаблон My-Day-test.md](../web/My-Day-test.md) пригодится, если тестового файла ещё нет.

## Срок доступа и восстановление

- При истечении доступа или ответе Drive HTTP 401 нажми «Подключиться снова» и подтверди доступ в Google при запросе. Сайт перечитает выбранный файл. Чтобы попробовать этот путь сразу, на личном устройстве нажми «Отключиться», затем «Подключиться снова».
- Если Google отозвал доступ к файлу или аккаунт его не видит, проверь аккаунт и право редактирования. Через «Выбрать файл» укажи тот же тестовый Markdown. Черновик привязан к его Drive ID. В личном режиме «Отключиться» позволяет выбрать другой аккаунт при следующем входе.
- Если результат отправки неизвестен, «Проверить и повторить» ищет метку и точный текст на Drive. При совпадении повтор обходится без записи. При конфликте текста сайт сохраняет черновик для ручной сверки. Проверка версии перед записью обнаруживает изменения между чтениями. Одновременные действия других клиентов между финальной проверкой и обновлением по-прежнему возможны.
- В общем режиме до подтверждения записи держи вкладку открытой. В личном режиме браузер сохраняет настройки и черновик в этом профиле. Если браузер блокирует сохранение, сайт показывает предупреждение. Ошибка чтения сохраняет время последнего успешного чтения либо явно показывает, что файл ещё предстоит прочитать.

## Настройка Google, если нужно сверить параметры

В Google Cloud Console выбери существующий проект и открой **APIs & Services → Enabled APIs & services**. Для проекта должны быть включены Google Drive API и Google Picker API. В Google Auth Platform у веб-клиента указан точный origin сайта без пути, а личный аккаунт добавлен в тестовые пользователи. Ошибку `SERVICE_DISABLED` в 0.1.1 устранило включение Google Drive API именно в проекте OAuth-клиента.

Ключ Picker ограничивается по HTTP referrer сайта и API в Cloud Console. В поле My Day вводится только этот браузерный ключ. OAuth client secret, access/refresh token и ключи моделей для настройки не нужны. Сайт получает краткоживущий токен от Google при явном нажатии кнопки. Помощник использует собственное подключение Drive.
