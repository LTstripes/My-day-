**Ближайший шаг владельца** — открыть сайт в своём браузере, подключить Drive и найти знакомую фразу в выбранном тестовом Markdown. Нажатие на результат должно открыть фрагмент с подсветкой. Для проверки достаточно чтения. [Шаги приёмки 0.5.0](GETTING_STARTED.md#поиск-в-050)

**Локальная среда проверена 25 ноября.** В `D:\My day` готовы `main`, независимая `test` и рабочая копия в `projects\codex`. Планировщик Windows запускает `MyDay-WorkspaceQuarantine` ежедневно в 19:00 по местному времени. Первый запуск через Планировщик завершился с кодом 0, свежая копия осталась на месте. Перенос после семи суток и защита незавершённой работы проверены на временных репозиториях, по 90 проверок в Windows PowerShell 5.1 и PowerShell 7. [Организация проекта в PR #12](https://github.com/LTstripes/My-day-/pull/12) · [Папки, расписание и восстановление](WORKSPACE.md)
